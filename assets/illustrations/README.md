# Najma illustrations

Every file in this folder is generated by `tools/illustrations` (see its README). Edit the scene sources there and rebuild; hand edits here are overwritten.

## What is here

| Files | Where they appear |
| --- | --- |
| `hero-*.svg` | The artwork beside each page's heading, one per page. |
| `about-*`, `cafe-chat`, `join-*`, `lessons-*`, `model-*`, `org-team` | Editorial scenes that `js/utils.js` places beside named section headings. |
| `spot-*.svg` | Small scenes at the top of study-area, option and offer cards. |
| `*-still.svg` | Motionless twins of the animated files, served when a visitor asks for reduced motion. |

`assets/teachers/amina-placeholder.svg` comes from the same build. It shows only the teacher's initial until an approved photograph exists.

## Sources and licences

- **People.** Figures are drawn from [Open Peeps](https://www.openpeeps.com/) by Pablo Stanley, released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The vector parts are read from the MIT-licensed [react-peeps](https://github.com/CeamKrier/react-peeps) package. The original linework is kept as drawn; the build adds skin tones and Najma colours and composes the scenes.
- **Shapes and star.** The Material 3 Expressive shapes and the eight-pointed Najma star follow `tools/shapes.py` and `assets/brand`.
- **Lettering.** The initial on the profile placeholder is Roboto Flex, under the SIL Open Font License 1.1.

CC0 asks for no attribution; the credit above is a courtesy to the artist.

## Motion

Animated files carry their own CSS. Entrances play once, and gentle loops (floating cards, twinkling stars, typing dots) run for about half a minute before settling, so an idle page does no drawing work. The `@media (prefers-reduced-motion: reduce)` rule inside each file also stops everything, and the pages swap in the `-still` twins through `<picture>`.
