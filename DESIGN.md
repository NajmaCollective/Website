# Najma · Material 3 redesign

The site uses Google Material Web 2.4.1 as its sole UI component library and Google Material Symbols Outlined for every icon. Material 3 Expressive supplies the shape library, the spring motion curves and the corner scale. Native HTML provides semantic tables, disclosure panels and lists. No other visual framework or icon library is used. Illustrations are built from Open Peeps figures in the Najma palette (see below).

## Identity

The logo pairs Najma's eight-pointed star, set inside a twelve-lobed Material "cookie" shape, with a wordmark drawn from Roboto Flex. The dot on the j is a small terracotta star. Files live in `assets/brand/`: the full logo and its reverse, the mark and its reverse, the wordmark, `favicon.svg` and `apple-touch-icon.png`. `tools/build_brand.py` regenerates them from the Roboto Flex variable font (`python3 tools/build_brand.py path/to/RobotoFlex.ttf`). The header and footer carry the logo inline so both stars can turn on hover.

## System

- **Colour.** Material 3 colour roles in `css/tokens.css`. Forest green anchors the identity, with mint, sage and peach containers. Dark bands (`.tone-inverse` and the footer) re-scope the colour roles, so Material components inside them adapt automatically. Tonal sections take `.tone-primary`, `.tone-secondary`, `.tone-tertiary` or `.tone-inverse`.
- **Type.** Roboto Flex throughout, the variable member of Material's Roboto family. Display and headline styles use heavier weights and a slightly wider setting.
- **Shape.** `css/shapes.css` is generated by `tools/build_shapes_css.py`. Every shape (Sunny, Very Sunny, the Najma star, cookies, clovers, Soft Burst, pentagon) is a clip-path polygon with the same point count, so any shape can morph into any other with a CSS transition.
- **Illustration.** Every page opens with a hero scene, and chosen sections carry an editorial scene. People come from Open Peeps (CC0), recoloured with five skin tones and the Najma palette and drawn with one ink colour; props, speech bubbles, Material shapes and the Najma star complete each scene. Study-area, option and offer cards open with a small spot scene. `tools/illustrations` builds all of it; `assets/illustrations/README.md` lists sources and licences.
- **Icons.** Material Symbols label actions only: buttons, the menu, the profile toggle and location pins. Section headings open with a two-tone brand rule that draws in as the heading scrolls into view.
- **Portraits.** Teacher photographs stand in arched windows on tonal panels, echoing the Teachers hero. Until a photograph is approved, the arch shows the teacher's initial.
- **Motion.** Hero artwork rises in on load and drifts gently with page scroll. Movement inside each illustration (floating windows, speech bubbles, twinkling stars) plays for about half a minute and then settles, so idle pages do no drawing work. Editorial scenes fade up as they scroll into view, and card spots lift on hover. Buttons tighten their corners on press. Every scroll-linked effect is progressive: browsers without scroll timelines show the finished state. `prefers-reduced-motion` swaps in still copies of the artwork and removes all movement.
- **Layout.** From 1024px, section headings take a left column and reading content a right column; a section's illustration sits in the heading column beneath its heading. Card grids, option cards and steps run the full width in a 3+2 or 2+2 arrangement. Tonal bands use `overflow: clip` so scroll-linked motion inside them follows the page.

## Maintenance notes

- The Material Symbols stylesheet is subset with `icon_names=` to the icons the site uses, which keeps the font small. When you add a new icon anywhere (HTML or JavaScript), add its name to that list in every page's `<head>`, keeping the list in alphabetical order, or the icon will show as its name in plain text.
- Hero artwork and card spots are referenced from each page's HTML. `js/utils.js` places the editorial scenes beside named section headings, each with its alt text and a reduced-motion source. To change or add artwork, edit `tools/illustrations/scenes/` and run `npm run build` there.

## Behaviour and accessibility

The carousel supports touch scrolling and focusable keyboard navigation with Arrow Left, Arrow Right, Home and End. Previous/next controls appear when Material Web is available. It never advances automatically. Reduced-motion preferences disable smooth movement. Navigation uses a native disclosure at smaller widths and closes on Escape or an outside click. Colour-role text pairs were checked at 4.5:1 or above. Forced-colour outlines and reduced-transparency fallbacks are included.

Teacher profiles remain unpublished until `confirmed: true` is explicitly added to verified records in `js/teachers-data.js`. Optional `services` values are `intro` and `short`. Area and service filters combine, including links arriving with query parameters. The current repository contains draft teacher records, so an honest enquiry state is shown. Draft event information is described as awaiting confirmation.

The editorial and teacher-preview injection in `js/utils.js` finds headings by their visible text, ignoring the decorative Material Symbols ligature inside each heading. Teacher previews replace the bracketed placeholder paragraphs in the matching sections. If you rename a heading, update its entry in `js/utils.js` to match.

## Validation

Run `node tests/interactions.cjs` for DOM-boundary tests of filtering, publication status, escaping, carousel controls and menu dismissal. Run `node --check js/utils.js` and `node --check js/teachers.js` for syntax checks.

The six HTML documents were checked for internal links, fragment targets, a single non-empty H1 and unique IDs. Material colour-role contrast checks passed. `git diff --check` passed.

The illustration redesign was reviewed in Chromium at 390px, 768px and 1440px on all six pages, and at 2x pixel density for the artwork, with reduced motion and with forced colours. A text comparison confirmed that every visible text run is unchanged. Alt text now describes the new artwork, and the screen-reader-only licence note about the earlier Material-icon artwork was removed. Each page loads without console errors or broken images, serves the still artwork under reduced motion, and every scroll-linked reveal completes on a 1440 by 1600 screen and a 390 by 844 phone. Once the artwork settles, an idle page uses no main-thread time. `tests/interactions.cjs` fails with the same pre-existing error before and after: its fixtures expect a service filter and carousel that the current pages no longer have.
